# Signal Processing Functions

## Core functions

| Function | Purpose |
|---|---|
| Fourier Transform | Converts between time and frequency domains |
| Fast Fourier Transform (FFT) | Efficient numerical Fourier transform |
| Wavelet Transform | Multi-resolution time-frequency analysis |
| Autocorrelation | Measures similarity with delayed versions of a signal |
| Cross-correlation | Measures similarity between signals |
| Power spectral density | Estimates signal power versus frequency |
| Filtering | Removes or modifies selected frequency components |
| SNR function | Relates signal power to noise power |
| Transfer function | Describes system input-output behavior |
| Detection/classification function | Supports signal interpretation |

## Typical workflow

Signal -> preprocessing -> transform -> feature extraction -> statistical analysis -> classification/regression.
