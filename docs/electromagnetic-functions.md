# Electromagnetic Functions

## Core functions

| Function | Purpose |
|---|---|
| Maxwell's equations | Fundamental electromagnetic field relationships |
| Wave propagation function | Models electromagnetic wave travel |
| Attenuation function | Represents energy loss during propagation |
| Phase function | Describes phase evolution |
| Polarization function | Represents electric-field orientation |
| Reflection coefficient | Quantifies reflected-field amplitude |
| Transmission coefficient | Quantifies transmitted-field amplitude |
| Impedance function | Represents electromagnetic impedance |
| Permittivity function | Describes electric material response |
| Permeability function | Describes magnetic material response |
| Absorption coefficient | Quantifies absorbed energy |
| Resonance function | Describes frequency-dependent resonant behavior |

## Supporting mathematics

- Complex numbers
- Differential equations
- Vector calculus
- Fourier analysis
- Boundary-value problems
- Numerical linear algebra
