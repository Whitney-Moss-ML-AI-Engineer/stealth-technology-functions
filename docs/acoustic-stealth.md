# Acoustic Signature Functions

## Function categories

| Function | Purpose |
|---|---|
| Sound-pressure function | Represents acoustic pressure |
| Acoustic absorption function | Models energy absorbed by materials |
| Acoustic attenuation function | Models reduction in sound intensity |
| Frequency-spectrum function | Describes frequency content |
| Vibration-damping function | Models structural vibration reduction |
| Acoustic scattering function | Models interaction with sound waves |
| Cavitation model | Studies bubble-related acoustic phenomena |
| Acoustic signature function | Quantifies acoustic observability |

## Common analysis tools

- Fourier analysis
- Spectrograms
- Power spectral density
- Cross-correlation
- Filtering
- Time-frequency analysis
