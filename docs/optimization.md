# Optimization and Machine Learning Functions

## Optimization functions

| Function | Purpose |
|---|---|
| Objective function | Defines what is being optimized |
| Cost function | Quantifies optimization error or expense |
| Loss function | Quantifies model error |
| Fitness function | Scores candidate solutions |
| Gradient function | Provides local optimization direction |
| Constraint function | Defines allowable design space |
| Pareto objective | Supports multi-objective trade studies |
| Bayesian optimization | Efficiently searches expensive design spaces |
| Genetic-algorithm fitness | Supports evolutionary search |

## Machine-learning applications

- Signature prediction
- Surrogate modeling
- Parameter estimation
- Classification
- Regression
- Anomaly detection
- Design-space exploration
- Uncertainty quantification

ML models should be evaluated using appropriate validation, uncertainty analysis, and domain constraints rather than treated as replacements for physical models.
