# Geometric and Surface Functions

Geometry strongly affects electromagnetic scattering and other observable signatures.

## Function categories

| Function | Purpose |
|---|---|
| Surface-normal function | Computes local surface orientation |
| Curvature function | Quantifies local surface curvature |
| Surface-area function | Computes surface area |
| Aspect-angle function | Relates geometry to observation direction |
| Boundary-surface function | Represents computational boundaries |
| Mesh-generation function | Discretizes geometry for simulation |
| Shape-optimization function | Optimizes geometric parameters |
| Surface-parameterization function | Represents geometry using mathematical parameters |

## Supporting mathematics

- Vector geometry
- Differential geometry
- Parametric surfaces
- Computational geometry
- Numerical meshing
