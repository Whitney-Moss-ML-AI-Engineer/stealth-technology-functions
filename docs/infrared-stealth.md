# Infrared and Thermal Signature Functions

## Function categories

| Function | Purpose |
|---|---|
| Planck radiation law | Models spectral blackbody radiation |
| Stefan-Boltzmann law | Relates temperature to total radiative emission |
| Thermal radiation function | Models emitted thermal energy |
| Conduction function | Models heat transfer through solids |
| Convection function | Models heat transfer between surfaces and fluids |
| Thermal diffusion function | Models temperature evolution |
| Thermal emissivity function | Represents surface emission characteristics |
| Spectral radiance function | Represents radiated energy by wavelength |
| Infrared signature model | Quantifies thermal observability |

## Engineering variables

- Temperature
- Emissivity
- Wavelength
- Surface area
- Thermal conductivity
- Heat capacity
- Fluid velocity
- Ambient conditions
