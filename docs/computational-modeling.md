# Computational Modeling Functions

## Major numerical methods

| Method | Typical application |
|---|---|
| Finite Difference Time Domain (FDTD) | Time-domain electromagnetic simulation |
| Method of Moments (MoM) | Integral-equation electromagnetic analysis |
| Finite Element Method (FEM/FEA) | Field and structural problems |
| Computational Fluid Dynamics (CFD) | Fluid and thermal-flow analysis |
| Boundary Element Method (BEM) | Boundary-value problems |
| Ray tracing | Geometric wave propagation approximation |
| Monte Carlo simulation | Probabilistic and uncertainty analysis |
| Numerical integration | Approximation of continuous mathematical quantities |
| Numerical linear algebra | Solution of discretized physical systems |
| Mesh generation | Converts geometry into computational elements |

## Model-development pipeline

1. Define the physical problem.
2. Define assumptions and boundary conditions.
3. Parameterize geometry and materials.
4. Generate a computational representation.
5. Select a numerical method.
6. Solve the model.
7. Verify numerical convergence.
8. Validate against appropriate reference data.
9. Perform sensitivity and uncertainty analysis.
10. Document assumptions and limitations.
