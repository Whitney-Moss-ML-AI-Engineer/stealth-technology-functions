# Radar-Absorbent Material Functions

Radar-absorbent materials are studied through their electromagnetic material properties and frequency response.

## Function categories

| Function | Purpose |
|---|---|
| Permittivity function | Models dielectric response |
| Permeability function | Models magnetic response |
| Complex impedance | Models material/interface behavior |
| Dielectric-loss function | Models dielectric energy dissipation |
| Magnetic-loss function | Models magnetic energy dissipation |
| Skin-depth function | Estimates electromagnetic penetration depth |
| Absorption coefficient | Measures absorbed electromagnetic energy |
| Frequency-response function | Describes response over frequency |
| Layer-thickness model | Studies multilayer material behavior |

## Variables

- Relative permittivity
- Relative permeability
- Conductivity
- Frequency
- Layer thickness
- Temperature
- Incident angle
- Polarization
