# Optical and Visual Observability Functions

## Function categories

| Function | Purpose |
|---|---|
| Reflectance function | Measures reflected optical energy |
| Absorption function | Measures absorbed optical energy |
| Spectral-response function | Describes response across wavelengths |
| Contrast function | Quantifies object/background difference |
| Visibility function | Quantifies visual detectability |
| Radiance function | Represents emitted/reflected optical energy |
| Color-matching function | Models colorimetric relationships |
| Image-segmentation function | Supports object/background analysis |
